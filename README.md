# Mushroom Classification Using Machine Learning

A reproducible comparison of three supervised machine-learning algorithms for classifying mushrooms as **edible** or **poisonous** using the UCI Mushroom dataset.

## Models

- Decision Tree
- Random Forest (100 trees)
- Support Vector Machine (RBF kernel)

The project retains the original three-algorithm scope and improves the workflow with categorical one-hot encoding, stratified train/test splitting, model pipelines, SVM scaling, classification metrics, confusion matrices, and stratified cross-validation.

> **Safety disclaimer:** This is an educational benchmark project only. Never use this model to identify wild mushrooms or make decisions about eating them. A model prediction is not a food-safety assessment.

## Dataset

The data file contains 8,124 instances, 22 categorical input attributes, and one binary class label (`e` = edible, `p` = poisonous). The source data includes `?` values for unknown `stalk-root` entries; these are retained as a categorical value instead of dropping those rows.

The dataset is the UCI Machine Learning Repository Mushroom dataset. See the [UCI dataset page](https://archive.ics.uci.edu/dataset/73/mushroom) and the included `data/agaricus-lepiota.names` file for source details and attribute descriptions.

## Setup and run

Python 3.10 or newer is recommended. From the repository root:

```bash
python -m venv .venv

# Windows PowerShell
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
jupyter notebook notebooks/mushroom_classification.ipynb
```

The notebook resolves the dataset relative to the repository root, so it can be launched from the root directory or from the `notebooks` directory.

## Methodology

1. Load the original categorical dataset and inspect class balance and unknown values.
2. Separate the target from the 22 input attributes.
3. Split the data into 80% training and 20% test sets using stratification and `random_state=42`.
4. Apply `OneHotEncoder(handle_unknown="ignore")` inside a scikit-learn `Pipeline`/`ColumnTransformer`.
5. Train Decision Tree, Random Forest, and RBF-kernel SVM classifiers. SVM uses `StandardScaler(with_mean=False)` after one-hot encoding.
6. Evaluate test-set accuracy, poisonous-class precision, recall, F1-score, and confusion matrices.
7. Estimate accuracy with 5-fold stratified cross-validation. Preprocessing is refitted inside each fold.
8. Inspect Random Forest encoded-feature importances.

## Results from the enhanced implementation

|---|---:|---:|---:|---:|---:|
| Decision Tree | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 ± 0.0000 |

## Limitations

- This is a static, tabular benchmark dataset, not an image-recognition or field-identification system.
- High benchmark accuracy must not be interpreted as safety assurance.
- The SVM uses the default `C` and `gamma` settings; no hyperparameter search is claimed.
- Feature importance from a Random Forest is model-specific and should not be interpreted as causal evidence.
